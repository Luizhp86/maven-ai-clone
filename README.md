# Maven AI Solutions Clone

Este projeto é um clone do site Maven AI Solutions, desenvolvido utilizando as seguintes tecnologias:

- Next.js
- React
- Tailwind CSS
- Shadcn UI
- TypeScript

## Funcionalidades

- Design responsivo que replica o site original
- Animações e transições fluidas
- Formulário de contato funcional integrado com Netlify Forms
- Páginas de casos de estudo
- Página de serviços com tabelas de preços e comparativos
- Página administrativa para visualização de submissões

## Como clonar e executar o projeto

```bash
# Clonar o repositório
git clone https://github.com/Luizhp86/maven-ai-clone.git

# Entrar no diretório do projeto
cd maven-ai-clone

# Instalar dependências
bun install

# Executar em modo de desenvolvimento
bun run dev

# Construir versão de produção
bun run build
```
